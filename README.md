Proyecto SQL - Daniel Rocha

Este repositorio contiene los ejercicios y desarrollos de bases de datos correspondientes a la semana actual del bootcamp. El objetivo principal es Introducción a Bases de Datos Relacionales.

📋 Contenido del Proyecto
Scripts de Creación: Archivos .sql para definir las tablas y relaciones.
Consultas (Queries): Scripts con resoluciones a problemas específicos planteados en clase.

🛠️ Tecnologías Utilizadas
Motor de Base de Datos: SQLite
Herramientas de Gestión: SQLite

🚀 Instrucciones de Uso
Clona este repositorio:
Ejecuta el script de creación en tu entorno local: archivo_creacion.sql.
Prueba las consultas incluidas en los archivos de ejercicios.
