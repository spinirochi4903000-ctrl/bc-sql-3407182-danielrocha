Semana 03 — DML: Manipulación de Datos 📊

Bienvenido a la documentación de la tercera semana del bootcamp. En esta etapa, el proyecto bc-sql-3407182-danielrocha se enfoca en cómo interactuar con los datos dentro de las estructuras creadas anteriormente.

🎯 Objetivos de la Semana
Basado en el currículo de referencia, los objetivos principales son:

Insertar datos: Dominar el uso de INSERT INTO tanto para filas únicas como para inserciones múltiples.
Actualizar registros: Modificar información existente de manera precisa mediante UPDATE.
Eliminar de forma segura: Aplicar sentencias DELETE comprendiendo el uso de filtros para evitar la pérdida accidental de datos.

📂 Estructura de esta Sección
Siguiendo la metodología de trabajo, este módulo se divide en:

Teoría: Conceptos fundamentales sobre la manipulación de registros y manejo seguro de datos.

Prácticas:
  
  Ejercicio 01: Inserción y consulta básica de datos.
  
  Ejercicio 02: Actualización de estados y eliminación controlada de registros.

Proyecto Semanal: Poblar el dominio asignado con datos reales para simular un entorno de producción.

🛠️ Comandos Implementados
En los scripts de esta semana encontrarás ejemplos de:


    -- Inserción
    INSERT INTO tabla (columna1, columna2) VALUES (valor1, valor2);


    -- Actualización
    UPDATE tabla SET columna = nuevo_valor WHERE condicion;


    -- Eliminación
    DELETE FROM tabla WHERE condicion;
