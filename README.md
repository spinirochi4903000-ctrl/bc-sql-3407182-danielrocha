Semana 06 — Funciones de Agregación 📊

Esta sección del proyecto está dedicada al análisis de datos masivos mediante el uso de funciones que permiten resumir y agrupar información para obtener métricas clave del negocio.

🎯 Objetivos de Aprendizaje

Basados en el currículo de esta semana:

1. Cálculos Estadísticos: Dominar el uso de COUNT, SUM, AVG, MIN y MAX para obtener totales, promedios y valores extremos.

2. Agrupamiento de Datos: Implementar la cláusula GROUP BY para organizar los resultados según categorías específicas.

3. Filtrado de Grupos: Aplicar condiciones sobre datos agregados utilizando la cláusula HAVING.

📂 Contenido de la Semana
Siguiendo la metodología de trabajo, este módulo se organiza en:
  
01 — Funciones de agregación: Conceptos y sintaxis básica.
  
02 — GROUP BY: Lógica de agrupamiento de registros.
  
03 — HAVING: Diferencias clave entre WHERE y HAVING.

Ejercicios de Práctica:

Ejercicio 01: Agregación básica (Totales y promedios).

Ejercicio 02: Uso avanzado de GROUP BY y HAVING.

Proyecto Semanal: Aplicación de reportes agregados sobre el dominio de datos asignado.
