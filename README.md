Semana 09 — JOINs: INNER JOIN y LEFT JOIN 🔗

Esta sección del proyecto marca un hito fundamental en el dominio de SQL: la capacidad de combinar datos provenientes de múltiples tablas para generar información compleja y relacional.

🎯 Objetivos de la Semana

Siguiendo el plan de estudios, los objetivos principales son:

1. Combinación de datos: Aprender a unir dos tablas mediante INNER JOIN utilizando la cláusula ON para establecer la relación.

2. Inclusión de registros sin coincidencia: Implementar el uso de LEFT JOIN para asegurar que las filas de la tabla principal se mantengan incluso si no hay una relación en la tabla secundaria.

3. Consultas Multi-tabla: Construir sentencias que involucren más de dos tablas utilizando alias de tabla para mantener la legibilidad y precisión.

📂 Contenido y Estructura

El trabajo de esta semana se organiza en los siguientes módulos basados en la metodología de referencia:

1. Teoría:

    ○ INNER JOIN: Intersección de conjuntos de datos.
   
    ○ LEFT JOIN: Persistencia de la tabla izquierda.
   
    ○ Conceptos avanzados: Introducción a RIGHT JOIN y FULL OUTER JOIN.

2. Prácticas:

    ○ Ejercicio 01: INNER JOIN básico y consultas multi-tabla.

    ○ Ejercicio 02: LEFT JOIN y detección de registros "huérfanos".
   
3. Proyecto Semanal: Aplicación de JOINs sobre el dominio de datos del bootcamp para generar reportes integrados.
