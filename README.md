Semana 07 — NULL y Constraints 🛡️

Esta sección del proyecto se enfoca en garantizar la integridad de los datos y el manejo correcto de la información ausente o desconocida mediante el uso de NULL y restricciones de tabla (Constraints).

🎯 Objetivos de la Semana

Basados en el currículo de referencia:

1. Manejo de NULL: Entender que NULL representa un valor desconocido (no es cero ni un espacio vacío).

2. Transformación de Datos: Aprender a filtrar y transformar valores nulos utilizando IS NULL, COALESCE, IFNULL y NULLIF.

3. Integridad de Esquemas: Aplicar restricciones fundamentales para asegurar la calidad de los datos: NOT NULL, UNIQUE, CHECK, PRIMARY KEY y FOREIGN KEY.

📂 Contenido y Estructura

El trabajo de esta semana se organiza en los siguientes módulos:

1. Teoría:

    ○ Conceptos sobre el valor desconocido (NULL).
  
    ○ Uso de funciones de control de nulos (COALESCE, NULLIF).
  
    ○ Estudio de Constraints para la integridad de datos.

2. Prácticas:

    ○ Ejercicio 01: Técnicas de manejo y recuperación de registros con NULL.

    ○ Ejercicio 02: Implementación de restricciones y verificación mediante PRAGMA.

3. Proyecto Semanal: Refuerzo de la estructura del dominio de datos aplicando las restricciones aprendidas para evitar inconsistencias.
