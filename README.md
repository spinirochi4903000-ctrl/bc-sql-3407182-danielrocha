Semana 05 — Operadores y Filtros 🛠️

Esta sección del proyecto está dedicada a profundizar en la recuperación de datos mediante el uso de filtros avanzados y operadores lógicos. En esta fase, el repositorio ha alcanzado 5 commits que reflejan el avance en la implementación de consultas complejas.


🎯 Objetivos de la Semana
Basándonos en la estructura de referencia, los objetivos principales son:


1. Filtros Compactos: Implementar el uso de los operadores BETWEEN, IN y NOT IN para simplificar las condiciones de búsqueda.

2. Patrones de Texto: Dominar el operador LIKE y el uso de comodines para realizar búsquedas parciales y flexibles.

3. Lógica Compleja: Componer filtros avanzados combinando múltiples operadores para extraer información específica.

📂 Contenido y Estructura

Siguiendo la metodología de trabajo sugerida, el contenido se organiza de la siguiente manera:

01 — BETWEEN e IN: Fundamentos para filtrar rangos de valores y pertenencia a listas.

02 — LIKE y coincidencia de patrones: Técnicas de búsqueda de cadenas de texto.

03 — Filtros combinados: Integración de múltiples criterios de selección.

Ejercicios Prácticos: Resolución de problemas aplicando los operadores mencionados.

Proyecto Semanal: Aplicación de filtros reales sobre el dominio de datos del bootcamp.
